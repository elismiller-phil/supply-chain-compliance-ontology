# supply-chain-compliance-ontology
supply chain compliance ontology

This repository contains exploratory ontology modeling work based on a
six-week applied ontology workshop organized by John Beverly.

The project explores how ontology and knowledge graph techniques can
represent supply chain compliance challenges in the natural products
industry.

The domain includes:
- regulatory differences across markets
- compliance verification
- ingredient testing
- communication across organizations
- knowledge gaps in supply chain governance
